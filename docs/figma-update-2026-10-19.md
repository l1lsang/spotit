# Figma 수정본 반영 · 2026-10-19

원본: [스팟잇 · 모바일 화면](https://www.figma.com/design/OBPR728dI5F6DFRwI24q3c?node-id=3-2)

모바일 390px 화면의 디자인 컨텍스트와 렌더링 이미지를 기준으로 기존 React/CSS 컴포넌트를 수정했습니다. 공통 스타일은 데스크톱에서도 동일하게 적용하되 기존 반응형 레이아웃을 사용합니다.

## UI와 고정 문구

- 기록 상세 `41:2`: 제목 오른쪽 더보기 버튼. 작성자 메뉴는 수정 → 공유 → 삭제, 다른 사용자는 공유·핀 신고·작성자 신고, 비로그인 사용자는 공유. 기존 수정 폼·공유 API·삭제 확인과 연결했습니다. 방향키, Home/End, Escape, Tab, 바깥 클릭을 지원합니다.
- 피드 `36:2`: 테두리가 없는 반경 선택과 원형 위치·새로고침 버튼.
- 그룹 상세 `38:2`: 공유 버튼을 제목 옆으로 이동, 그룹 공개 범위 문구 간소화, 탈퇴·지도 보기 버튼 테두리 제거.
- 사람 찾기 `43:2`, 채팅 목록 `45:2`, 좋아요 `46:2`: Figma에서 삭제한 새로고침 버튼과 보조 설명을 제거. 불러오기 실패 시 다시 시도는 제공합니다.
- 프로필 `42:2`, `64:2`, 설정 `47:2`: 설정 버튼, 타인 앨범 새로고침 버튼, 앨범 캡션·공개 아이콘 배경, 설정 패널 배경 반영.
- 알림 `40:2`: 모두 읽음 버튼과 푸시 패널의 테두리 제거.
- 채팅방 `44:2`: 상단 버튼 모양, 상대 말풍선 테두리, 사진·아바타 그림자 조정. 사진 신고는 메시지 메뉴에서 제공합니다.
- 가입 `34:2`: 약관 동의 영역 외곽선 제거.
- 홈 `32:2`: “지도를 펼쳐보기” → “지도로 바로가기”, 하단 “스팟잇 · 오늘, 이곳” → “스팟잇”. 홈·로그인에서 삭제된 로고 제작 문구를 제거하고 가입 화면에는 유지합니다.
- 로그인 `35:2`: 기본 화면에서 삭제된 Google 로그인 안내는 로그인 오류가 발생할 때 표시합니다.
- 약관·개인정보·운영·청소년·위치정보 문구도 Figma와 대조했습니다. 동적 날짜·연락처 결합을 제외한 본문은 기존 코드와 일치합니다.

## JSON 예시 데이터

사용자 확인에 따라 변경 대상은 화면 제작에 사용하는 JSON 예시 데이터입니다. `src/data/previewContent.json`에서 게시물과 그룹의 문구를 관리합니다.

| 기존 제목 | 새 제목 | 확인한 노드 |
| --- | --- | --- |
| 조금 더 걷고 싶은 날 | 산책하던 중에 찍은 사진 | `36:73`, `109:3509` |
| 계획에 없던 쉬어감 | 예쁜 카페 발견 | `36:133`, `109:3559` |

세 게시물 본문도 Figma와 대조해 JSON에 포함했습니다. 상세·프로필·내 기록 프레임에 남은 이전 제목 대신, 피드와 그룹 목록에서 변경한 제목을 JSON 원본으로 삼아 모든 미리보기 화면에 일관되게 표시합니다. 첫 번째 그룹의 삭제된 소개 문구도 반영했습니다.

`npm run dev:design`으로 `http://127.0.0.1:5241/feed`에서 JSON 데이터가 연결된 전체 앱을 확인할 수 있습니다. `scripts/design-preview.mjs`와 `design/preview/fixtures.js`가 실제 화면 컴포넌트에 예시 데이터를 제공합니다. 미리보기의 Firebase 클라이언트는 비활성화되며 운영 데이터는 수정하지 않습니다. 일반 `npm run dev`와 프로덕션 빌드는 기존 서비스 데이터를 사용합니다.

## 자산과 검증

- 기존 로고·사진·Lucide 아이콘을 재사용합니다. 더보기 아이콘은 `41:2`의 `1:3495` SVG를 `public/icons/post-more.svg`에 다운로드했습니다. 원본 34×34 크기를 유지합니다.
- 기존 앱의 Pretendard 글꼴과 색상 토큰을 사용합니다. Figma 제작 과정의 Noto Sans KR 대체 글꼴 때문에 글자 폭은 약간 다를 수 있습니다.
- 브라우저 검증은 실제 컴포넌트와 격리된 서비스 데이터를 사용하며, 실제 Firebase 쓰기 검증과는 구분합니다.
- 빌드, 소스 ESLint, 피드/채팅·그룹 탐색·프로필 앨범 테스트 19개 통과. 320·390·768·1440px에서 화면 13개씩 검증했고 더보기 메뉴의 작성자/방문자/비로그인 권한, 키보드, 바깥 클릭, 공유, 수정창, 삭제 취소·성공·오류 및 신고 연결을 확인했습니다.
- 독립 미리보기 실행 명령에서도 목록 6곳·상세 3곳의 JSON 제목/본문, 빈 그룹 소개, 메모리 내 수정 저장·새로고침 초기화, 320px 더보기 메뉴를 확인했습니다. 해당 흐름에서 Firebase 요청이 발생하지 않는 것도 확인했습니다.
