## 구현을 확인해 반영한 사실

| 확인 영역 | 문서에 반영한 범위 |
| --- | --- |
| 인증·프로필 서비스 및 가입 화면 | 이메일·외부 로그인, 공개 프로필 필드, 온보딩. 연령·보호자 확인은 현재 없음 |
| 기록 서비스와 Firestore 규칙 | 나만 보기·팔로워·전체 공개. 비공개 계정은 팔로우 승인 설정이며 프로필 전체를 숨기지 않음 |
| 지도·장소 검색 | 브라우저 현재 위치 요청과 지도 API 검색, 서버에 저장된 기록 좌표. 지속적인 백그라운드 이동 추적 없음 |
| 채팅·알림·푸시 | 참여자·본문·사진·파일명·읽음 정보·FCM 토큰. 개인정보 처리 항목에 포함 |
| 탈퇴·Storage 처리 | 주요 회원 데이터 삭제와 채팅 표시 변경은 있으나 사진 파일·푸시 토큰·관리 증거·백업까지 완전 파기한다고 단정할 수 없음 |
| `functions/moderation.js` | 일반 신고와 사진 신고의 증거 범위, 관리자 검토·핀 숨김·계정 정지, `us-central1` 서버 처리 |

사진 신고는 세 가지 출처(기록·프로필·채팅)를 구분합니다. 서버가 현재 원본과 접근 권한을 확인하고 선택한 사진 URL·작성자·원본 식별정보를 저장합니다. 일반 채팅방 신고와 달리 최근 20개 메시지를 추가 증거로 복사하지 않습니다. 사진 파일 복제본을 만드는 구현은 없으며 URL이 폐기되면 증거 미리보기가 사라질 수 있습니다. 같은 사진의 중복 신고를 구분하고, 기록 사진에 대한 숨김은 핀 전체에 적용됩니다. 사진 자체가 얼굴·주소·위치를 드러낼 수 있다는 점도 정책에 반영했습니다.

## 시행 전에 확정할 사항

| 항목 | 필요한 작업 |
| --- | --- |
| 아동 가입·동의 | 연령 확인, 법정대리인 동의·실제 동의 확인, 아동용 설명, 권리 행사 및 동의 기록 관리. 보호자 체크박스만으로 확인을 대체하지 않음 |
| 약관·개인정보 고지와 동의 | 이용약관 동의, 처리 목적별 법적 근거·고지, 필요한 별도 동의와 버전·시각 기록, 기존 회원에 대한 변경 안내 |
| 운영자·담당자 | 주소의 공식 표기와 개인정보 보호·청소년보호 담당자 지정을 확인하고 추가 연락 채널을 확정 |
| 위탁·국외 이전 | 실제 계약 법인·연락처, DB·Storage·호스팅 지역과 재수탁자, 이전 국가·항목·시기·방법·목적·기간·근거·거부 방법 확인. Vercel 설정 파일만으로 실제 호스팅 계약을 확정하지 않음 |
| 보유·파기 | 신고 증거·조치 이력·숨김 자료·로그·동의 이력의 구체적 기간과 근거, 파일·토큰·백업 정리, 탈퇴 실패 재시도와 삭제 결과 검증 |
| 위치정보 | 서비스 신고 등 적용 의무 검토, 개인위치정보 이용·제공 동의와 제공 시 통지, 이용·제공 사실 확인자료 자동 기록·보존, 법정대리인·보호의무자 권리 처리 |
| 운영 조치 | 피해 긴급도 분류, 콘텐츠 조치·대상자 통지·이의제기 절차, 사진 URL 접근 폐기와 증거 보존의 역할·기간 구분 |
| 문서 시행 | 위 절차와 실제 배포 설정을 검증하고 시행일·버전을 확정. 검토본 배너만 제거하여 시행하지 않음 |

현재 작업은 정책 작성과 사진 신고 구현입니다. 보호자 인증, 새 동의 저장 시스템, 보관 기간에 따른 일괄 삭제, 위치정보 법정 기록 시스템은 이 변경에 포함되지 않습니다.

## 확인한 1차 자료

- 개인정보 처리 목적·항목·기간·위탁·권리·파기 등 방침 기재 사항: [개인정보 보호법 제30조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398435).
- 만 14세 미만 아동의 동의가 필요한 개인정보 처리에는 법정대리인 동의와 그 확인이 필요함: [개인정보 보호법 제22조의2](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398523).
- 국외 이전 근거와 고지 항목은 실제 처리 관계에 맞춰 확정: [개인정보 보호법 제28조의8](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1033215841).
- 개인위치정보 제공 대상·목적에 대한 동의와 제공 시 통지: [위치정보법 제19조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900341061). 브라우저 위치 권한이나 기록 공개 선택만으로 관련 절차를 모두 이행했다고 단정하지 않음.
- 이용·제공 사실 확인자료 등의 기록·보존 기준 확인: [위치정보의 보호조치 기준](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000279386). 현재 앱에 자동 기록 시스템이 있다는 의미가 아님.
- 청소년 정의(19세 미만, 19세가 되는 해의 1월 1일을 맞이한 사람 제외): [청소년 보호법 제2조](https://www.law.go.kr/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1000085006).
- Firebase 서비스별 처리와 지역·삭제 관련 안내, Authentication의 미국 처리: [Firebase Privacy and Security](https://firebase.google.com/support/privacy). 모든 Firebase 데이터가 한 국가에 있거나 탈퇴 즉시 모든 백업에서 삭제된다고 표시하지 않음.

## 검증·배포

`npm run build`로 타입·문서 번들·라이선스 목록을 확인하고 `npm run lint`로 정적 검사를 수행합니다. 신고 API는 데모 Auth·Firestore·Functions 에뮬레이터에서 `npm run test:moderation`과 `npm run test:photo-reports`로 검증합니다. 로컬 설정과 검증 범위는 [관리자 기능 설정](admin-setup.md)을 참고하세요.

사진 신고는 서버 변경이 포함되어 프런트엔드와 Functions를 함께 배포해야 합니다. 이 작업에서 운영 서비스 배포는 실행하지 않았습니다.
