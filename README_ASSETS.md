## 사용 방법
1. 이 압축파일을 기존 랜딩페이지 프로젝트 루트에 압축 해제합니다.
2. 프로젝트의 Claude Code에서 `CLAUDE_CODE_PROMPT.md` 내용을 작업 지시로 전달합니다.
